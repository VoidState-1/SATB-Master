# SATB Master Basic Choir

`default.sf2` is the built-in offline playback bank for SATB Master. It contains
two General MIDI presets used by the four voice tracks:

- Program 52: `SATB Choir Aahs`
- Program 53: `SATB Voice Oohs`

The bank is generated from mathematical waveforms and contains no external
recorded samples. Run `npm run generate:soundfont` to reproduce the binary and
its SHA-256 file. Redistribution terms and provenance are recorded in
`LICENSE-default-soundfont.txt`.
