# 教材测试用例与本地分析材料

人工审阅可使用软件工具栏的 **教材审计**，接口及操作见 [可视化审计区](../Docs/audit-workspace.md)。首批本地 v2 包为 `Pilot/2026-11-17/pilot-v2.satb-audit.json`，包含逐条独立工程及预审问答，仍属于被忽略的中间材料。

## Git 保存的内容

- `Verified/`: 仅放经人工核准并完成验证的最终教材测试用例。当前尚无用例完成整谱核准并晋升至此目录。
- [Samples](./Samples/): 已有简写接口的工具示例, 是代码测试夹具, 不属于教材识谱金标准。
- 本说明文件。

最终用例保留复现所需的谱面输入、确定预期、必要条件、精确教材出处和核准信息。应报错的反例同样可以作为最终用例; 验证的是预期结论, 不要求每例零诊断。分析草稿、原图、逐次报告、推导结果转储和重复生成工程不随最终用例提交。

`.gitignore` 默认忽略 `StandardCase` 的其他内容。只有人工核准并验证后, 才将最终版本放入 `Verified/`, 不以改变目录或强制添加的方式代替核准。

## 仅保留本地的内容

- `Origin/`: 用户提供的教材 PDF。
- `Pilot/`: 转写初稿、候选标注、裁图、对照报告、原始诊断、审计清单、执行产物与补丁审阅副本。
- 后续其他分析/工作目录同样默认忽略。

首批试验材料保留在本地 `Pilot/2026-11-17/`, 其中 `review/audit-queue.md` 保存待审问题。首轮程序修复、单元测试新增、临时执行脚本和集成测试已撤销; 历史副本保留于该批次的 `review/reverted-code/`, 不作为当前实现。

## 候选与最终版本的边界

候选参考必须区分教材明示标签、模型解释和程序输出。两次 AI 一致或程序通过均不能代替人工核准。保留原图、初稿、修订理由和全部诊断, 但将它们留在本地分析目录。

参考放在 `.satbt` 的 `reference` 层, 不作为盲推导的已知输入。错误/警告采用较严格标准, 建议可宽松分析; 口径疑点先找依据、归类并交人工审阅。不要为了消除诊断而改动原谱或调整默认推导参数。尚有歧义或验证未完成的版本继续留在本地候选集。
