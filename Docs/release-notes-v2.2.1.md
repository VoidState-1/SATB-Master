# V2.2.1

## 修复

- 自动输入和半音移调时，小调导音优先使用升高七级的正确拼写。例如 F♯ 小调使用 E♯，C♯ 小调使用 B♯，并支持需要重升号的导音。
- 修复错误拼写导致的导音解决检查漏报，五线谱预览沿用正确的书写音高。
- 五度、八度规则覆盖反向连续进行及复音程，排除持续音、重复同音和休止间隔。

## 兼容性

- 工程格式、自然小调音阶及已有规则配置不变。
- 已保存音符的拼写保持原样。旧工程中已误写为 F♮ 等音名的音符，可在属性面板的“同音异名”中改为正确导音。

## 构建

Windows x64 NSIS 安装包：`SATB-Master-Setup-2.2.1-x64.exe`。
