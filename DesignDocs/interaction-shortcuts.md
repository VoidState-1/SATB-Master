# SATB Master 交互快捷键设计

> 状态：已实施（用户确认项与 P1）
> 分支：`codex/interaction-improvements`  
> 日期：2026-07-26  
> 平台：Windows 10/11  
> 本文记录快捷键的作用域、已实施行为和暂缓边界，与当前分支实现保持一致。

## 1. 目标

本轮快捷键升级服务于高频和声输入，而不是追求快捷键数量。目标如下：

1. 减少选择、绘制、擦除和切换声部之间的工具栏往返。
2. 让音符与和弦区域沿用一致的选择、剪贴板和时间移动语义。
3. 阻止浏览器默认行为侵入桌面编辑器，例如 `Ctrl+A` 选中整页文字。
4. 在输入框、下拉框、弹窗和浮动调色盘中保留正常的文字编辑与焦点导航。
5. 所有批量操作继续遵守锁定区间、锁定轨道和单次撤销原则。

文档使用以下状态：

- **升级前已有**：本轮开始前已经实现并继续保留。
- **本轮已实施**：用户确认的需求与 P1 建议，已经进入当前分支。
- **暂缓**：有价值，但当前容易产生冲突或需要更完整的功能基础。

## 2. 快捷键作用域

### 2.1 三种输入上下文

快捷键不能继续只依靠“事件目标是不是输入框”判断，应明确区分三个上下文：

| 上下文 | 典型位置 | 允许的快捷键 |
| --- | --- | --- |
| 全局命令 | 工具栏、空白区域、编辑器 | 保存、打开、撤销、重做、播放等不依赖编辑域的命令 |
| 编辑器命令 | 音符卷帘、和弦轨、标尺轨 | 工具、选择、声部、量化、剪贴板、移动、缩放和导航 |
| 文本/弹窗 | 输入框、文本域、下拉框、确认框、和弦调色盘 | 原生文字编辑、焦点导航和弹窗自身按键；不得泄漏到编辑器 |

中央编辑器需要维护“最后活动编辑域”：

- `notes`：音符卷帘。
- `chords`：和弦轨。
- `ruler`：标尺轨，默认沿用上一个音符或和弦编辑域。

点击工具栏不会清除最后活动编辑域；进入输入框或弹窗时编辑器快捷键暂停。

### 2.2 文本输入保护

当焦点位于以下元素时，只保留明确的全局文件命令，其他编辑器按键不得触发：

- `input`、`textarea`、`select`。
- `contenteditable` 元素。
- 原生下拉菜单打开期间。
- 确认框、和弦调色盘和后续模态窗口。

输入框中的 `Ctrl+A`、`Ctrl+X`、方向键、`Home`、`End`、`Space` 和 `Tab` 必须保持系统原义。

### 2.3 修饰键和窗口焦点

- 本项目只定义和测试 Windows 键位，文档统一写作 `Ctrl`，不额外设计 macOS 映射。
- 修饰键临时工具必须同时监听 `keydown`、`keyup` 和窗口 `blur`。
- 应用失去焦点、打开系统对话框或使用 `Alt+Tab` 时必须清空临时工具状态，避免回到窗口后工具卡住。
- 自动重复的 `keydown` 不得重复创建历史命令或重复切换声部。

## 3. 本轮升级前已经实现的快捷键

### 3.1 全局与工程命令

| 快捷键 | 当前行为 | 作用域与备注 |
| --- | --- | --- |
| `Ctrl+S` | 保存工程 | 非输入控件；未命名工程会进入另存为流程 |
| `Ctrl+Shift+S` | 工程另存为 | 当前由 `Ctrl+S` 分支读取 `Shift` 实现 |
| `Ctrl+O` | 打开工程 | 会执行现有的未保存内容确认流程 |
| `Ctrl+Z` | 撤销 | 使用工程历史记录 |

| `Ctrl+Y` | 重做 | Windows 兼容键位 |
| `Space` | 播放/暂停 | 输入控件内不触发 |

本轮升级前尚未实现 `Ctrl+N` 新建工程快捷键；实施结果见 6.1。

### 3.2 选择、剪贴板与删除

| 快捷键 | 当前行为 | 作用域与备注 |
| --- | --- | --- |
| `Ctrl+C` | 复制选中事件 | 有和弦选择时复制和弦，否则复制音符；保留多选相对时间 |
| `Ctrl+V` | 粘贴事件 | 以播放头作为最早事件的起点；粘贴结果成为新选择 |
| `Delete` / `Backspace` | 删除选中事件 | 有和弦选择时删除和弦，否则删除音符；仍受锁定约束 |

本轮升级前尚未接管 `Ctrl+A` 和 `Ctrl+X`：

- `Ctrl+A` 会落入 Chromium 默认行为并选中界面文字。
- `Ctrl+X` 没有编辑器命令。

### 3.3 音符与和弦变换

| 快捷键 | 当前行为 | 作用域与备注 |
| --- | --- | --- |
| `←` / `→` | 按当前吸附网格向前/向后移动 | 同时支持音符选择和和弦选择 |
| `↑` / `↓` | 音符升高/降低一个半音 | 只作用于音符；单音选择会发出预览音 |
| `Shift+↑` / `Shift+↓` | 音符升高/降低一个八度 | 只作用于音符 |
| `Q` | 将选择起点量化到当前网格 | 音符当前使用就近取整；和弦当前向前取整，实施时应确认是否统一 |

方向键批量移动继续合并为一次历史命令；任何越界或锁定错误由领域命令统一拒绝。

| 快捷键 | 当前行为 | 作用域与备注 |

| `3` | 擦除工具 | 同上 |

| `Home` / `End` | 面板分隔条最小/最大尺寸 | 只在分隔条获得键盘焦点时 |

## 5. 用户确认且本轮已实施

### 5.1 选择工具的临时工具

| 输入 | 临时有效工具 | 松开后 |
| --- | --- | --- |
| 按住 `Ctrl` | 铅笔工具 | 返回选择工具 |
| 按住 `Alt` | 擦除工具 | 返回选择工具 |

详细规则：

1. 只在基础工具为“选择”时生效；基础工具是铅笔、擦除或切分时不改变工具。
2. 临时工具同时作用于音符卷帘和和弦轨，保持两条轨道的工具语言一致。
3. `Alt` 优先于 `Ctrl`；同时按住时使用擦除工具。
4. 工具栏保留基础工具选择，但按钮和鼠标指针应清楚显示当前临时有效工具。
5. `Ctrl+A`、`Ctrl+X`、`Ctrl+滚轮` 等组合命令优先执行其命令语义；只有指针在编辑器内按下时才把单独按住的 `Ctrl` 解释为临时铅笔。
6. 松开修饰键、窗口失焦、弹出文件对话框或取消当前手势时立即复原。
7. 拖动已经开始后，松开修饰键不改变本次手势类型；鼠标松开提交后才恢复基础工具，避免一次拖动中途从绘制变成选择。

### 5.2 `Tab` 循环切换当前声部

| 快捷键 | 行为 |
| --- | --- |
| `Tab` | 女高音 → 女低音 → 男高音 → 男低音 → 女高音 |
| `Shift+Tab` | 按相反顺序循环 |

建议细则：

- 仅在音符编辑域活动且没有输入控件/弹窗占用焦点时接管 `Tab`。
- 工具栏、检查器、面板分隔条和弹窗仍保留标准 `Tab` 焦点导航。
- 跳过不可见声部；锁定声部不跳过，因为用户仍可能需要检查、试听或修改非音符属性。
- 切换后左侧声部高亮、当前输入声部提示和新绘制音符的目标声部同步更新。
- 如果只有一个声部可见，则保持当前声部，不产生通知或历史记录。

### 5.3 `Ctrl+鼠标滚轮` 横向缩放

- 向上滚动放大时间轴，向下滚动缩小时间轴。
- 使用与工具栏相同的缩放范围：`42–140 px/beat`。
- 缩放必须以鼠标指向的时间位置为锚点：缩放前后，鼠标下的 tick 尽量保持在同一屏幕横坐标。
- 只在标尺轨、和弦轨或音符卷帘上阻止默认行为；侧栏和检查器中的 `Ctrl+滚轮` 不应误改时间轴。
- 连续滚轮输入可以逐帧更新视图，但不写入工程历史，也不触发自动保存。

### 5.4 `Ctrl+A` 全选

推荐采用“最后活动编辑域”语义：

- 音符域：选择工程时间范围内所有**可见声部**的音符，不只选择当前屏幕或当前声部。
- 和弦域：选择和弦轨内的全部和弦区域。
- 标尺域或没有明确编辑域时：沿用上一次音符/和弦编辑域；首次默认音符域。
- 锁定事件允许被选择、检查和复制，但后续编辑命令仍由锁定约束决定是否允许。
- 无论是否存在事件，都必须 `preventDefault()`，彻底阻止整页文字被选中。

如果希望 `Ctrl+A` 永远只选择音符，也可以在实施前取消和弦域分支；从一致性和后续可扩展性考虑，本文推荐按活动编辑域全选。

### 5.5 `Ctrl+X` 剪切

- 选择类型沿用 `Ctrl+C`：有和弦选择时剪切和弦，否则剪切音符。
- 剪贴板负载与现有复制格式完全一致，粘贴仍以播放头为最早事件起点。
- 剪切必须是原子操作：先验证整组选中事件可删除，再更新剪贴板并提交一次删除历史记录。
- 任一事件受锁定轨道、锁定区域或练习锁定区间保护时，整体拒绝；不得只剪切可编辑子集。
- 操作失败时保留原编辑器剪贴板内容，避免一次失败剪切覆盖用户之前复制的内容。

### 5.6 双击非当前声部音符切换声部

- 只在有效工具为“选择”时触发，避免和铅笔双击绘制、擦除或切分发生冲突。
- 双击音符后将该音符所属声部设为当前声部。
- 第一次点击仍执行正常单选和音频预览；第二次点击不额外创建历史记录。
- 双击当前声部音符不做额外动作。
- 切换声部不改变播放头，不修改工程，也不绕过声部锁定。

## 6. 补充的常用快捷键

P1 已经随本轮升级实施；P2 仍保持暂缓，不加入当前默认键位。

### 6.1 P1：已实施

| 快捷键 | 建议行为 | 理由 |
| --- | --- | --- |
| `Ctrl+N` | 新建工程 | 与现有新建按钮和桌面软件惯例一致 |
| `Esc` | 分层取消 | 先取消手势/关闭浮层，再清除选择；不修改工程 |
| `Ctrl+Shift+A` | 清除全部事件选择 | 与 `Ctrl+A` 成对，避免依赖点击空白区 |
| `Ctrl+D` | 就地重复选中事件 | 音乐编辑中的高频输入，可保留多选相对结构 |
| `Home` | 播放头回到工程开头 | 对应现有“回到开头”按钮 |
| `End` | 播放头移到工程末尾 | 与 `Home` 对称 |
| `PageUp` / `PageDown` | 播放头移动到上一/下一小节起点 | 比按网格逐格移动更适合和声导航 |
| `Shift+滚轮` | 横向滚动时间轴 | 与普通滚轮纵向滚动、中键自由平移互补 |
| `[` / `]` | 切换到更粗/更细的吸附网格 | 高频输入时无需打开右上角下拉框 |
| `Ctrl+-` / `Ctrl+=` | 以视口中心缩小/放大时间轴 | 为没有精确滚轮的设备提供键盘替代 |

`Ctrl+D` 推荐语义：复制选择并把副本的最早起点移动到原选择最晚结束位置，保留内部间隔、声部、时值和和弦结构；整批操作只产生一次撤销记录，碰撞或锁定时整体拒绝。

`Esc` 推荐优先级：

1. 关闭确认框或浮动调色盘。
2. 取消尚未提交的绘制、擦除、框选、移动、缩放或切分预览。
3. 清除音符/和弦选择。
4. 没有可取消内容时不做任何事。

### 6.2 P2：工作流增强，暂缓

| 快捷键 | 候选行为 | 需要确认的原因 |
| --- | --- | --- |
| `I` / `O` | 将循环起点/终点设为播放头 | 易记，但属于视频/DAW 混合惯例 |
| `L` | 开关循环播放 | 单键容易误触，需要确认是否接受 |
| `M` | 静音当前声部 | 与“节拍器”含义可能混淆 |
| `S` | 独奏当前声部 | 与保存的 `Ctrl+S` 不冲突，但单键误触成本较高 |
| `F` | 将视图定位到当前选择 | 需要先定义横向与纵向适配范围 |

当前已提供“设置 > 快捷键”页面，支持搜索、单命令重映射、清除、恢复单项默认和恢复全部默认。重复键位会在录入时拒绝，偏好保存在本机 `localStorage`，不写入 `.satb` 工程。`Ctrl+滚轮`、`Shift+滚轮`和临时工具修饰键属于固定手势，不在重映射列表中。

## 7. 冲突处理规则

快捷键按以下优先级解析：

1. 系统/原生文件对话框。
2. 模态确认框与浮动调色盘。
3. 输入框、文本域、下拉框及可编辑文本。
4. 明确组合命令，例如 `Ctrl+S`、`Ctrl+A`、`Ctrl+X`、`Ctrl+滚轮`。
5. 正在进行的指针手势。
6. 临时工具修饰键。
7. 编辑器单键命令，例如 `Q`、`1–4`、方向键和 `Tab`。
8. 浏览器默认行为。

只要某个编辑器命令被识别，就必须调用 `preventDefault()`；被高优先级上下文拒绝的按键则保留其原生行为。

## 8. 建议的实现结构

### 8.1 基础工具与有效工具分离

当前 `tool` 状态应拆分为：

```ts
baseTool: 'select' | 'pencil' | 'eraser' | 'split'
modifierState: { control: boolean; alt: boolean }
effectiveTool: EditorTool
```

`effectiveTool` 只用于指针命中、光标和工具按钮临时反馈；`baseTool` 才是用户通过 `1–4` 或工具栏永久选择的工具。

### 8.2 集中管理编辑器快捷键

建议把 `App.tsx` 中不断增长的全局 `keydown` 分支迁移到独立 Hook，例如 `useEditorShortcuts`：

- 输入：工程命令、选择状态、活动编辑域、基础工具、播放状态和网格。
- 输出：修饰键状态和必要的编辑域回调。
- 只负责按键解析，不直接改写工程对象。
- 所有修改仍调用现有命令层，继续获得锁定检查、批量历史和通知。

音符画布保留与命中测试相关的双击和滚轮逻辑，但命令语义通过上层回调执行。

### 8.3 选择域

新增显式状态：

```ts
type EditorDomain = 'notes' | 'chords'
```

点击音符、音符空白区或钢琴键区时设为 `notes`；点击和弦区域或和弦轨空白区时设为 `chords`。全选、剪切、复制、粘贴、删除、重复和清选统一读取该状态，不再依赖“哪一种选择集合非空”猜测用户意图。

## 9. 验收与回归测试

### 9.1 新增功能

- 按住/松开 `Ctrl`、`Alt` 时有效工具正确变化，基础工具不变。
- `Ctrl+Alt` 使用擦除工具；窗口失焦后恢复选择工具。
- 临时工具开始拖动后，松开修饰键不会改变当前手势类型。
- `Tab` 和 `Shift+Tab` 按固定顺序循环声部，并跳过不可见声部。
- 输入框、下拉框、调色盘和确认框中的 `Tab` 不切换声部。
- `Ctrl+滚轮` 缩放后鼠标下 tick 的屏幕位置误差不超过 1 px，并遵守缩放上下限。
- `Ctrl+A` 不再选中页面文字；音符域和和弦域分别选择正确事件集合。
- `Ctrl+X` 成功时可撤销且可粘贴；锁定失败时工程和剪贴板均不变化。
- 双击非当前声部音符切换声部，双击当前声部音符无额外副作用。

### 9.2 现有行为回归

- `Ctrl+S`、`Ctrl+Shift+S`、`Ctrl+O`、撤销和重做保持可用。
- `Ctrl+C` / `Ctrl+V` 的音符与和弦负载不混淆。
- `Space` 播放/暂停继续真正取消音频调度。
- `1–4` 不会从和弦调色盘、输入框或确认框泄漏到编辑器。
- 方向键移动、移调和 `Q` 量化继续只生成一次历史记录。
- 恢复提示出现后，所有原生下拉菜单仍可首次点击。
- 左右下方面板分隔条获得焦点时，方向键仍优先调整面板，不移动音符。

### 9.3 键盘状态边界

- 按住 `Ctrl` 或 `Alt` 后使用 `Alt+Tab` 离开并返回应用，不得残留临时工具。
- 按键自动重复不会连续切换多个声部，除非该行为被明确设计为可重复导航。
- 中文输入法组合输入期间，字母单键命令不得误触发。
- 应用最小化、最大化和恢复窗口后，快捷键作用域和编辑域保持一致。
