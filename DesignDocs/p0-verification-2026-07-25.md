# SATB Master P0 阶段验证记录

> 验证日期：2026-07-25
> 验证系统：Windows 10 22H2 x64（10.0.19045）
> 应用版本：0.1.0

## 本阶段完成内容

- 使用项目自有的确定性加法合成波形生成默认 SF2，不包含第三方录音采样。
- 默认 SF2 由 Electron Main 从开发目录或安装包 `resources/soundfonts` 读取并校验 SHA-256。
- 修复沙箱化 Electron 生产环境 preload 格式，使用 `preload.cts -> preload.cjs` 提供真实 IPC。
- 配置 electron-builder 26.15.3 与 NSIS，生成 Windows x64 安装程序和免安装目录。
- 增加专用应用图标及可复现 PNG/ICO 生成脚本。
- 增加启动恢复信封、恢复提示、来源路径、显式保存后清理和浏览器预览回退。
- 增加打包桌面端自动回归，覆盖卷帘输入、规则检查、撤销/重做、播放、工程和 MIDI 往返。
- 增加同声部音符重叠、换调边界导音解决和七和弦七音下行解决规则，并补充最小正反例。
- 用户 SF2 工程引用支持按绝对路径重新读取和摘要复核；文件缺失或被替换时明确回退，且可恢复默认音色。
- v1 工程读取增加完整结构与数值边界校验，避免畸形 JSON 在界面、规则或播放阶段才触发异常。
- 音符编辑命令统一拒绝越界音高、力度及非整数或非有限时间值，防止应用生成无法重新打开的工程。
- 修复 SF2 AudioWorklet 未连接系统输出导致的全程静音；SF2、回退音色与节拍器现共用可测量主输出总线。
- 暂停会取消尚未触发的 SF2 事件并关闭主输出闸门；再次播放或绘制音符时恢复输出，不再只暂停界面动画。
- 卷帘点击改为向前吸附到当前网格起点；中键专用于拖动画布；Windows 系统边框替换为自定义标题栏和窗口控件。
- 音符拖绘与选择工具缩放采用“起点向前、终点向后”的区间吸附；时值对齐控件排除窗口拖拽命中并修正首次激活。
- Windows 无边框窗口首次显示时等待原生激活事件，再把输入焦点交给网页，避免原生下拉框的第一次点击只激活窗口。
- 恢复、新建、打开和关闭确认统一改用应用内模态框，避免浏览器同步确认框退出原生模态循环后破坏下拉菜单状态。
- 卷帘音符块显示实际音名；单音选择与移动提供预听，多选保持静音；拖擦期间即时隐藏待删除音符且松开后仍批量提交。
- 应用启动后即初始化音频引擎并预载默认 SoundFont，播放与换音色的并发加载按顺序执行。
- 和弦区域绘制完成或双击已有区域时打开五列浮动调色盘，可快速设置级数、变化音、性质、转位和副属目标。

## 已验证

- `npm test -- --run`：6 个测试文件、35 项领域测试通过。
- `npm run typecheck`：Renderer 与 Electron 严格类型检查通过。
- `npm run dist:win`：资源生成、生产构建、x64 NSIS 安装包生成通过。
- 免安装目录端到端回归通过。
- 最终安装程序已静默安装到隔离目录，安装后端到端回归通过，并完成卸载清理。
- 端到端流程创建 8 个四声部音符并识别平行五度与平行八度；撤销、重做、默认 SF2
  加载、播放、工程保存/重新打开、MIDI Type 1 五轨导出均通过。
- 用户 SF2 的路径读取、SHA-256 复核及工程重新打开后的自动加载在免安装版和安装版中均通过。
- 免安装版和安装版均验证默认/用户 SF2 产生非零主输出电平；播放暂停后输出归零，随后绘制音符仍能正常预听。
- 本地生产构建持续监测暂停后 800 ms 无未来音符或残响输出，并验证随后绘制音符可恢复预听。
- 本地生产 Electron 回归验证后半格点击不跳到下一格、中键拖动不改变当前工具，以及自定义窗口最大化/还原状态往返。
- 本地生产 Electron 回归验证应用首次点击即可切换时值网格，并核对拖绘、缩放保存后的结束位置均向后吸附。
- 本地生产 Electron 回归在任何控件输入前核对原生窗口与网页均已获得焦点。
- 本地生产 Electron 回归分别选择“恢复内容”和“不恢复”，两条路径均确认提示关闭后首次点击会实际展开原生下拉菜单。
- 本地生产 Electron 回归验证和弦绘制后自动打开调色盘、结构化选项生成 `V6/5/II`、双击重新打开并正确保存分析字段。
- 本地生产 Electron 回归核对 `C5/D5` 音高标签、单音选择与变调的非零输出、多选静音，以及擦除按下后提交前的画布像素变化。
- 本地生产 Electron 回归在播放或绘制前确认默认 SoundFont 已完成预载。
- 自动恢复写入、preload 读取、9 音符快照校验和显式保存后清理通过。
- `npm audit --omit=dev`：生产依赖 0 项已知漏洞。
